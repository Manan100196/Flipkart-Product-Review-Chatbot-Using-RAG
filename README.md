Flipkart Product Review Analysis Using RAG

This project implements a Retrieval-Augmented Generation (RAG)-based chatbot that analyzes 450 customer reviews of headphones and earphones from Flipkart.

The chatbot enables users to interact with customer reviews, extract key insights, and understand overall product sentiment through natural language queries.

The application leverages Google's embedding model for semantic search and Google's Large Language Model (LLM) to generate context-aware responses based on the retrieved customer reviews.
